## About
1 What this does (features / workflows)
- Python files that are used in videos on YouTube [channel](https://www.youtube.com/@jaskiret).
- Includes any Python version (3.6.2, 3.6.5, 3.9.4, 3.11.7).
- Includes any Python output: Jupyter, IDLE, CLI (Windows' CMD), and tkInter (Python library).

2 Why this is useful (purpose / objective)
- For the videos' audience to access the source code.
- For self-documentation of the evolution of how these Python files were developed.
